Démo interactive

Essaie le clavier créole dans ton navigateur

Ce simulateur exécute le vrai moteur de suggestions du clavier Android (dictionnaire, n-grammes, accents) directement dans la page : aucune donnée ne quitte ton navigateur.

Tape un mot, touche une suggestion pour l'insérer, ou reste appuyé sur une voyelle (a, e, i, o, u...) pour voir apparaître les accents. Le clavier de ton ordinateur fonctionne aussi directement.
